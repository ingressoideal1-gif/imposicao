## Correcao do backend QR

Entre 12h e 13h UTC ocorreram 466 GETs integrais de 24 MB do objeto privado
`ideal-control-master/qr_ideal_pool_qr12_1.bin` (11.184 GB). Nesse periodo,
`acesso-estacao` recebeu 839 lotes de credenciais. Seu `gravarLote` baixa a base
inteira para conferir contratos v2. O cache de modulo nao e compartilhado entre
instancias. A fonte publicada v264 foi baixada e comparada: coincide com a base
local, desconsiderando finais de linha.

Mudanca localizada: `acesso-estacao/index.ts` passa a conferir os mesmos hashes
de ingressos usando `qr_blocos.ts`. O leitor busca blocos de 65536 bytes via
Range, confere status 206, Content-Range, tamanho e SHA-256 fixo de cada bloco.
Nao faz fallback para baixar a base inteira. Cache compartilha requisicoes
concorrentes na mesma instancia; falhas sao removidas do cache. O ultimo bloco
tem tamanho ajustado. Todos os indices continuam limitados pelo contrato QR.

`qr_blocos_v2.json` contem somente hashes e metadados. Foi derivado em memoria
da base integral, apos conferir tamanho 24000000 e o SHA-256 ja fixado em
`preparacao_codigos.ts`. Nenhum codigo privado ou credencial foi salvo no Git.
Uma leitura real de Range confirmou HTTP 206 e 65536 bytes, com hash correto.
Para um lote que usa um bloco, a transferencia cai de 24 MB para 64 KiB;
lotes que atravessam fronteiras leem mais blocos. Nao altera numeração,
hashCodigo, autorizacao, sal, contratos, schema ou gravacao das credenciais.

Backup da fonte publicada para recuperacao: `.tmp-egress/supabase/functions`.
Alvo de eventual deploy: apenas `acesso-estacao`, mantendo verify_jwt=false
e a autenticacao propria ja existente. Recuperacao: republicar essa fonte
anterior. Os manifestos e o MSI nao participam desse deploy.

## Atualizador e publicador

- Reutiliza MSI somente apos conferir tamanho e SHA-256 dos bytes atuais.
- Falhas de download, hash e inicio de instalacao aguardam seis horas, com

- Falhas graves de MSI continuam bloqueadas ate tentativa humana ou nova

@types/node no node_modules compartilhado, antes de executar testes.
